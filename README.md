## Online-food-orders-and-customer-behavior-analysis.
### Project overview 
This project aims at investigating customers' ordering patterns and customer distribution. I used python to clean and inspect the data, then moved the data to MySQL for EDA and finally I shipped the data to Power BI using an ODBC for visualization.
## Tool Used
1. Python - data cleaning and inspection.
2. MySQL - Exploratory data analysis to understand the data.
3. Power BI - Data transformation, DAX for calculation and aggregation, data visualization.
